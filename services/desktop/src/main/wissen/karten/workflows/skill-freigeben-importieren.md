Neue oder geänderte Skills benutze ich erst, wenn du sie einmal freigegeben hast. So kann niemand einen Skill unbemerkt erweitern. Skills, die du selbst anlegst oder die ich dir im Chat anlege, sind sofort freigegeben.

Unter Einstellungen → Erweitert → Skills steht bei solchen Skills „Vertrauen prüfen“, bei geänderten „Erneut prüfen“. Der Dialog zeigt Name, Bereich, Beschreibung und welche Funktionen der Skill nutzen darf; neu hinzugekommene sind markiert. Mit „Vertrauen + aktivieren“ gibst du ihn frei, mit „Ablehnen“ bleibt er aus.

Skills von anderen holst du über „Importieren“ (als .zip-Paket oder einzelne SKILL.md) oder ziehst die Datei einfach auf den Bereich. Beim Import wählst du „Importieren + vertrauen“ oder „Nur importieren“. „Alle exportieren“ packt deine eigenen Skills zum Weitergeben, „Skills-Ordner öffnen“ zeigt, wo sie liegen. Skills liegen auf diesem Rechner; beim Umzug auf eine andere AVA gehen sie mit.
