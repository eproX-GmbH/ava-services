AVA gibt es auch als Server ohne Oberfläche. Er läuft rund um die Uhr, auch wenn dein Rechner aus ist. Du bedienst ihn über die AVA-App unter app.ava.bi, über Telegram oder, falls deine Organisation das erlaubt, aus Claude und ChatGPT; der Server gehört zu deinem Konto, nur du meldest dich dort an. Gebucht wird er in der AVA-App unter Mehr → Deine AVA bzw. von deinem Admin in der AVA Konsole; wird er dir dort noch nicht angeboten, klärst du das mit dem AVA-Team.

Eingerichtet wird er in seinen Server-Einstellungen: Anmeldung, KI-Modell (ChatGPT-Abo oder API-Schlüssel), Telegram, E-Mail und Umzug zwischen deinen AVAs. Den Link dorthin holst du in der AVA-App unter Mehr → Deine AVA → „Server-Einstellungen öffnen“. Öffne ihn innerhalb von 15 Minuten; danach bleibt die Seite offen, solange du sie nutzt. Deinen bisherigen Stand vom Rechner bringst du per Umzug auf den Server.

Grenzen: Der LinkedIn-Beobachter läuft nie auf dem Server. Workflows legst du dort im Chat an, einen Editor gibt es nicht. Läuft gleichzeitig deine Desktop-App, beantwortet der Server die Anfragen aus App und Claude bevorzugt.
