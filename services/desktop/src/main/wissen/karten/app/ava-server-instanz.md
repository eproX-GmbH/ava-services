AVA gibt es auch als Server ohne Oberfläche. Er läuft rund um die Uhr, auch wenn dein Rechner aus ist. Du bedienst ihn über die AVA-App unter app.ava.bi, über Telegram oder, falls deine Organisation das erlaubt, aus Claude und ChatGPT; der Server gehört zu deinem Konto, nur du meldest dich dort an. Ob eine solche AVA für dich eingerichtet werden kann, klärst du mit dem AVA-Team.

Eingerichtet wird er auf seiner Einrichtungsseite: Anmeldung, Modellzugang per Schlüssel oder ChatGPT-Abo, Telegram, E-Mail und Deine AVAs. Den Link dorthin holst du in der AVA-App unter Mehr → Deine AVA → „Server-Einstellungen öffnen“, er gilt 15 Minuten. Deinen bisherigen Stand vom Rechner bringst du per Umzug auf den Server.

Grenzen: Der LinkedIn-Beobachter läuft nie auf dem Server. Workflows legst du dort im Chat an, einen Editor gibt es nicht. Läuft gleichzeitig deine Desktop-App, beantwortet der Server die Anfragen aus App und Claude bevorzugt.
