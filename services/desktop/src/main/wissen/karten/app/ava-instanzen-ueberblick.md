AVA kann auf deinem Rechner laufen, auf mehreren Rechnern oder auf einem Server. Ich kann dir jederzeit sagen, welche deiner AVAs gerade verbunden ist und was sie übernimmt.

In der Desktop-App siehst du es unter Einstellungen → Konto → Deine AVAs. Die Tabelle zeigt je Gerät, ob es Desktop oder Server ist, die Version, ob es gerade verbunden ist, welcher Telegram-Bot dort hängt, ob der Firmen-Radar läuft, welches Modell aktiv ist und welche AVA die Anfragen aus Claude oder ChatGPT beantwortet. Laufen mehrere, hat der Server Vorrang vor dem Rechner. Mit dem Schalter darunter legst du fest, ob dieses Gerät solche Anfragen beantworten darf.

Ein Telegram-Bot darf nur an einer AVA hängen, Telegram lässt je Bot nur einen Abholer zu. Steht dort „auch an einer anderen Instanz“, leg für jede AVA einen eigenen Bot an. Den Namen dieser AVA in der Liste ändere ich dir auf Zuruf; er erscheint nach dem nächsten Verbinden.
