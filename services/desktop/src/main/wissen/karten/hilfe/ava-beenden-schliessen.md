Auf dem Mac läuft AVA weiter, wenn du nur das Fenster schließt: Verarbeitung, Zeitpläne und Telegram arbeiten dann im Hintergrund. Ganz beendest du AVA über das Menü „Beenden“ oder mit Cmd+Q. Unter Windows beendet das Schließen des Fensters die App.

Beim Beenden zeigt AVA kurz „Wird beendet …“. In der Zeit fährt sie die Dienste für die Verarbeitung und den Hintergrund-Browser herunter, unter Windows wartet sie dafür ein paar Sekunden länger. Bleibt das ungewöhnlich lange stehen, warte einen Moment; AVA beendet hängende Teile nach kurzer Zeit selbst und räumt beim nächsten Start übrig gebliebene Browser-Prozesse auf.

Musst du AVA einmal hart beenden, gehen keine Firmendaten verloren; begonnene Schritte setze ich nach dem nächsten Start fort. Passiert das häufiger, melde das Problem über „Problem melden“.
