AVA gibt es für macOS (Apple-Prozessor und Intel) und Windows. Beide Fassungen sind signiert: Unter Windows steht als Herausgeber eproX GmbH, unter macOS ist die App signiert und von Apple notarisiert.

Windows SmartScreen kann bei einer neuen Version trotzdem kurz warnen, solange sich das Vertrauen in die Datei noch aufbaut. Prüf dann, ob als Herausgeber eproX GmbH angezeigt wird; dann kannst du die Installation fortsetzen. Steht dort ein anderer oder gar kein Herausgeber, installiere die Datei nicht und lade sie neu von der AVA-Website.

AVA nimmt keine Verbindungen von außen an; alle Dienste auf deinem Rechner hören nur auf den Rechner selbst. Fragt die Firewall trotzdem nach, braucht AVA keinen eingehenden Zugang. Meldet dein Virenscanner eine blockierte Website, kann das eine Firmen-Website sein, die AVA gelesen hat; AVA führt von dort nichts aus. Lässt sich AVA gar nicht starten, schreib dem AVA-Team an info@eprox-gmbh.de.
